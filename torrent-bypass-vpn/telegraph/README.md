# Публикация гайда в Telegraph

Здесь лежит та же статья, свёрстанная под [Telegraph](https://telegra.ph): только поддерживаемые теги, без таблиц.

| Файл | Что это |
| --- | --- |
| `article.html` | исходный текст статьи — правьте здесь |
| `build.py` | пересобирает `content.json` и `preview.html` из `article.html` |
| `content.json` | готовое содержимое страницы для Telegraph API |
| `preview.html` | превью страницы, открывается в браузере |
| `images.json` | прямые ссылки на картинки из папки `../img` этого репозитория |
| `publish.py` | публикует страницу (Python 3.8+, без дополнительных пакетов) |

## Как опубликовать

Telegraph с сентября 2024 года не принимает загрузку картинок, поэтому страница берёт их по прямым ссылкам из этого репозитория. Ссылки уже прописаны в `images.json`.

```bash
cd torrent-bypass-vpn/telegraph
python publish.py --author "Название VPN"
```

Скрипт выведет ссылку на страницу и сохранит токен аккаунта Telegraph в `telegraph_token.txt`. Этот файл исключён из git: не публикуйте его, по токену можно редактировать ваши страницы.

Обновить уже опубликованную страницу:

```bash
python publish.py --edit <путь страницы после telegra.ph/>
```

## Как поправить текст

1. Измените `article.html`.
2. Запустите `python build.py`.
3. Опубликуйте заново или обновите страницу через `--edit`.

Если вы поменяли картинку в `../img`, сделайте коммит в ветку `main`: страница Telegraph подхватит новую версию по той же ссылке (GitHub может отдавать старую версию ещё несколько минут из кеша).
