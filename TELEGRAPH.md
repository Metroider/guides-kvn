# Как развернуть гайд в Telegraph

Каждый гайд в этом репозитории можно опубликовать в [Telegraph](https://telegra.ph) одной командой. Скрипт создаёт аккаунт Telegraph, публикует страницу со всеми картинками и выдаёт ссылку, которую можно отправить пользователям или закрепить в канале.

Картинки страница берёт прямо из этого репозитория, поэтому никуда загружать их не нужно. Telegraph с сентября 2024 года не принимает загрузку картинок, поэтому по-другому их на страницу не добавить.

Ниже пример для гайда `torrent-bypass-vpn`. Для других гайдов всё так же, меняется только папка.

## Что понадобится

- компьютер с Windows, macOS или Linux;
- Python 3.8 или новее (дополнительные пакеты не нужны);
- 5 минут.

## Шаг 1. Скачайте репозиторий

На странице репозитория нажмите **Code → Download ZIP** и распакуйте архив.

Или через git:

```bash
git clone https://github.com/Metroider/guides-kvn.git
```

## Шаг 2. Установите Python

- **Windows.** Скачайте установщик с [python.org](https://www.python.org/downloads/). На первом экране установщика поставьте галочку **Add python.exe to PATH**.
- **macOS.** Скачайте установщик с [python.org](https://www.python.org/downloads/). После установки откройте папку «Программы → Python 3.x» и запустите `Install Certificates.command`, иначе скрипт не сможет подключиться к Telegraph.
- **Linux.** Python обычно уже установлен. Проверьте командой `python3 --version`.

## Шаг 3. Откройте терминал в папке гайда

Нужна папка `torrent-bypass-vpn/telegraph`.

- **Windows.** Откройте папку в Проводнике, кликните в адресную строку, наберите `cmd` и нажмите Enter.
- **macOS.** Откройте «Терминал», напечатайте `cd ` (с пробелом), перетащите папку в окно терминала и нажмите Enter.
- **Linux.** `cd путь/к/guides-kvn/torrent-bypass-vpn/telegraph`

## Шаг 4. Опубликуйте страницу

Windows:

```bat
py publish.py --author "Название вашего VPN"
```

macOS и Linux:

```bash
python3 publish.py --author "Название вашего VPN"
```

`--author` — подпись под заголовком статьи, её можно не указывать.

Через пару секунд скрипт напечатает:

```
New Telegraph account; token saved to .../telegraph_token.txt
Done: https://telegra.ph/Kak-pustit-torrent-klient-mimo-VPN-v-Happ-i-INCY-11-21
```

Ссылка после `Done:` — готовая страница.

## Шаг 5. Сохраните токен

Рядом со скриптом появился файл `telegraph_token.txt`. Это ключ от аккаунта Telegraph, в котором создана страница.

- **Сохраните его в надёжном месте.** Без токена страницу больше нельзя будет изменить.
- **Никому не отправляйте и не коммитьте его.** По токену можно редактировать и подменять ваши страницы. В этом репозитории файл уже исключён из git через `.gitignore`.

## Как обновить страницу после правок

1. Скачайте свежую версию репозитория (или `git pull`).
2. Если скачивали ZIP заново, положите сохранённый `telegraph_token.txt` в новую папку `telegraph`.
3. Узнайте путь страницы — это часть ссылки после `telegra.ph/`. Если забыли, выполните:

   ```bash
   python3 publish.py --list
   ```

4. Перезапишите страницу:

   ```bash
   python3 publish.py --edit Kak-pustit-torrent-klient-mimo-VPN-v-Happ-i-INCY-11-21
   ```

Ссылка не меняется, подпись автора сохраняется. Чтобы сменить подпись, добавьте `--author "Новое имя"`.

Если вы заменили только картинку в папке `img` (под тем же именем) и сделали коммит в `main`, переопубликовывать ничего не нужно: страница подхватит новую картинку по той же ссылке. GitHub может отдавать старую версию ещё несколько минут.

## Как править страницу в браузере

Небольшие правки текста удобнее сделать прямо на telegra.ph:

1. Выполните:

   ```bash
   python3 publish.py --login
   ```

2. Скрипт выведет одноразовую ссылку. Откройте её в браузере в течение 5 минут — браузер привяжется к аккаунту Telegraph.
3. Откройте свою страницу: в правом верхнем углу появится кнопка **Edit**.

Учтите: правки, сделанные в браузере, затрутся при следующем запуске `publish.py --edit`. Если правите в браузере, перенесите те же изменения в `article.html`. Добавить новые картинки через редактор Telegraph нельзя — только через репозиторий.

## Как поправить текст в репозитории

1. Отредактируйте `article.html` в папке `telegraph`. Допустимые теги: `p`, `h3`, `h4`, `b`, `i`, `u`, `s`, `a`, `code`, `pre`, `br`, `hr`, `ul`, `ol`, `li`, `blockquote`, `aside`, `figure`, `figcaption`, `img`. Таблиц Telegraph не поддерживает.
2. Пересоберите страницу:

   ```bash
   python3 build.py
   ```

   Скрипт обновит `content.json` и `preview.html` и остановится с ошибкой, если в тексте есть тег, который Telegraph не поддерживает.
3. Откройте `preview.html` в браузере и проверьте результат.
4. Обновите страницу командой `publish.py --edit ...`.
5. Не забудьте обновить `README.md` гайда, чтобы версия на GitHub совпадала.

## Если картинки у читателей не загружаются

Картинки отдаются с `raw.githubusercontent.com`. Если у части читателей этот адрес не открывается, разместите картинки на другом хостинге с прямыми ссылками на файлы и замените ссылки в `images.json`. Затем выполните `publish.py --edit ...`.

## Без скрипта (только текст)

Откройте `preview.html` в браузере, выделите всё (Ctrl+A / Cmd+A), скопируйте и вставьте в редактор на [telegra.ph](https://telegra.ph). Заголовки, списки, жирный текст и ссылки сохранятся, а картинки — нет.

## Частые ошибки

| Сообщение | Что сделать |
| --- | --- |
| `'python' не является внутренней или внешней командой` | На Windows используйте `py` вместо `python`. Если не помогает, переустановите Python с галочкой **Add python.exe to PATH**. |
| `CERTIFICATE_VERIFY_FAILED` (macOS) | Запустите `Install Certificates.command` из папки «Программы → Python 3.x». |
| `urlopen error` или `timed out` | Сайт `api.telegra.ph` недоступен из вашей сети. Включите VPN и повторите. |
| `No direct links in images.json for: ...` | В `images.json` нет ссылки для указанных картинок. Добавьте их. |
| `telegraph_token.txt not found` | Команды `--list` и `--login` работают только после первой публикации. Если токен сохранён, положите его рядом со скриптом. |
| `Telegraph error in editPage: ...` | Проверьте путь страницы через `--list`. Страницу можно изменить только тем токеном, которым она создана. |
| `Telegraph error ...: ACCESS_TOKEN_INVALID` | Токен неверный или отозван. Верните правильный `telegraph_token.txt`. Если удалить файл, скрипт создаст новый аккаунт, но старые страницы через него изменить будет нельзя. |
